# IA3

System do statystycznej analizy krótkoterminowych ruchów SP500: silnik w Pythonie
szuka i ocenia strategie (mean reversion, momentum itp.), wyniki trafiają do
Firebase, Google Sheet je pokazuje, a dashboard na GitHub Pages liczy z nich
dzienną/2-dniową/3-dniową predykcję kierunku.

Zobacz `docs/ARCHITECTURE.md` po pełny opis architektury i plan wdrożenia.
